# Vendored dependency: Mermaid

- **Package:** mermaid
- **Version:** 10.9.1
- **Build:** UMD bundle (`dist/mermaid.min.js`) — self-contained, exposes `window.mermaid`
- **Source:** https://cdn.jsdelivr.net/npm/mermaid@10.9.1/dist/mermaid.min.js
- **sha256:** 61b335a46df05a7ce1c98378f60e5f3e77a7fb608a1056997e8a649304a936d6
- **License:** MIT (https://github.com/mermaid-js/mermaid/blob/v10.9.1/LICENSE)

Vendored so the browser board renders Mermaid diagrams offline, with no
third-party network requests by default (privacy-respecting). The module URL
can still be overridden via `BACKLOG_PY_BROWSER_MERMAID_URL` (e.g. to a CDN or
a newer local copy), or set to an empty string to disable diagram rendering.

To update: re-download the pinned version above, refresh the sha256, and run
`uv run pytest tests/test_browser_mermaid_config.py`.
